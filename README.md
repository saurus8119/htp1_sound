# HTPlex

HTPlex turns the HTP-1 into a network music player for Plex and Plexamp.

## Features

- Sign in to your Plex account from the HTP-1 add-on page.
- Select HTPlex as a playback destination in Plex or Plexamp.
- Uses the HTP-1 audio output with automatic sample-rate matching.
- Provides a simple add-on interface for Plex authorization.

## Installation

1. Open the HTP-1 **Add-ons** tab.
2. Install **HTPlex** from the add-on catalog.
3. Open the **HTPlex page in the Add-ons tab**.
4. Follow the on-screen instructions to authorize your Plex account.
5. Select **HTPlex** as the playback destination in Plex or Plexamp.
